# RegistroFRS 📋

Aplicación Android desarrollada en **Kotlin y Jetpack Compose** para gestionar y registrar incidencias diarias por parada, organizadas por meses.

## 🚀 Funcionalidades

- Registro de incidencias por parada y fecha.
- Eliminar incidencias registradas.
- Almacenamiento local mediante Room (SQLite).
- Consulta y organización de registros.

## 🛠️ Tecnologías

- **Lenguaje:** Kotlin
- **Interfaz:** Jetpack Compose
- **Arquitectura:** MVVM
- **Base de datos:** Room
- **Procesamiento:** KAPT

## 📱 Estado del proyecto

<code>Finalizado</code>

El objetivo es registrar incidencias por cada parada de TRAM y la exportación de registros a Excel.

## ⚙️ Requisitos

- Android Studio
- JDK 11
- Android SDK 24 o superior
